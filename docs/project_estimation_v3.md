# 阶段性开发工作量评估报表 (V3.0 - SEO 深度合规版)

本文件基于甲方提出的 8 点 SEO 补充要求，对 V2.0 评估进行了修正。重点增加了 **SSR/SSG 合规性**、**全自动 Hreflang 映射** 以及 **Schema 真实性校验** 的工作量。

## 1. SEO 技术合规与架构增强 (新增项) - 5 人日
这是确保 24 个语种站点不被 Google 判定为“重复内容”的核心架构工作。

| 任务 | 描述 | 预估工期 |
| :--- | :--- | :--- |
| **全自动 Hreflang 计算** | 动态生成 head 区域的 `rel="alternate"`，支持 24 个语种互联，无需手动填表。 | 1.5 人日 |
| **全站 SSG/SSR 改造** | 移除 `force-dynamic`，为所有 Product/Blog 路由实现 `generateStaticParams`。 | 1.5 人日 |
| **Metadata API 深度补全** | 实现严格的 Canonical 冲突检测、Robots 颗粒度控制、OG/Twitter 语义增强。 | 1 人日 |
| **Sitemap & 索引控制** | 优化 `sitemap.ts` 以包含交织链接，并实现 `noindex` 的 CMS 灵活开关。 | 1 人日 |

## 2. GSEO 提炼系统 (合规增强版) - 7 人日
强化了 Schema 与正文内容的一致性校验，符合甲方“真实性”要求。

- **CMS 字段增强**: 增加“AI 证据源”字段，记录 GSEO 提炼的原始段落依据 (1人日)
- **Schema 动态拆分**: 根据 PageType (Product/FAQ/Article) 自动注入对应的 JSON-LD (2人日)
- **AI 提炼流优化**: 调整 Gemini Prompt，强制要求输出内容必须包含页面内真实的锚点 ID (2人日)
- **Rich Results 验证周**: 针对 24 语种抽样进行 Google 结构化数据工具跑测与修正 (2人日)

## 3. 核心大子页实现 (SSG 适配版) - 10 人日
针对 ProductOverview、Blog、FAQ 的全量开发，增加 SSG 静态生成参数的联调。

## 4. 局部优化与 V2 二版迭代 - 8 人日
视觉精修、GSAP 动画调优、响应式性能指标 (LCP/CLS) 修复。

## 5. Payload CMS CDP 系统 - 7 人日
用户行为追踪、点击流分析仪表盘、数据可视化。

---

### 📊 财务/商务总结
- **总工期评估**: **37 人日** 
- **环比 V2.0 增量**: **+8 人日 (+27%)**
- **核心价值点**: 
  1. **规避惩罚**: 通过 Hreflang 和 Canonical 规避 24 语种站点的重复内容惩罚。
  2. **收录提速**: SSG 确保搜索引擎爬虫在 500ms 内抓取到完整渲染的页面。
  3. **数据真实**: 100% 匹配正文的 Schema 内容，建立极高的域名信任度。

> [!WARNING]
> **关键前置条件**: 实施“全自动 Hreflang”要求各语种路径结构必须保持高度的一致性（即 slug 在各语种下逻辑对齐），否则需要额外的 URL 映射表开发。
