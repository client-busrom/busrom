## 注意事项

1. **简体中文 (ZH_CN) vs 繁体中文 (ZH_TW)**
   - 已正确区分简繁体字符
   - 例如: 產品圖 (ZH_TW) vs 产品图 (ZH_CN)

2. **通用中文 (ZH)**
   - 使用简体中文作为通用中文 (ZH)
   - 与 ZH_CN 保持一致

3. **Description 字段**
   - MediaCategory 的 description 字段也包含完整的 EN/ZH/ZH_CN/ZH_TW
   - MediaTag 不需要 description 字段

4. **Slug 命名规则**
   - 使用英文小写 + 连字符
   - 产品系列: `series-{name}`
   - 规格: `spec-{name}`
   - 颜色: `color-{name}`
   - 场景: `scene-{name}`
   - 自定义: `custom-{name}`
